# 🌦️ Weather Application (Python)

A Python-based Weather Application that provides **real-time weather information** using the **OpenWeatherMap API**.  
This project includes **two versions**:
- ✅ Advanced Weather App (GUI-based)
- ✅ Simple Weather App (Jupyter Notebook)

It is suitable for **learning Python, API integration, and GUI development**.

---

## 📌 Features

### Advanced Weather App
- City-based weather search
- Light 🌞 / Dark 🌙 theme toggle
- Celsius / Fahrenheit unit switch
- Detailed weather metrics
- 5-day weather forecast
- Intelligent caching for better performance
- User-friendly GUI

### Simple Weather App
- Easy-to-use Jupyter Notebook
- Quick city-based weather lookup
- Clean and minimal interface
- Beginner-friendly

---

## 🛠️ Technologies Used
- Python 3.8+
- Tkinter (GUI)
- Requests (API handling)
- OpenWeatherMap API
- Jupyter Notebook

## 🚀 Installation & Setup

### 1️⃣ Clone the Project
```bash
git clone https://github.com/your-username/weather-application.git
cd weather-application
```

### 2️⃣ Install Required Libraries
```bash
pip install requests pillow
```

---

## ▶️ Step 3: Run the Applications

### 🌐 Advanced Weather App
```bash
python app.py
```

### 📓 Simple Weather App
1. Launch Jupyter Notebook:
```bash
jupyter notebook
```
2. Open `manage.ipynb`
3. Run all cells:
```
Kernel → Restart & Run All
```
